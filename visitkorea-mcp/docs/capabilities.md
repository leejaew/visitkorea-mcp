# Capabilities

The server exposes the existing 14 tools in stable order:

1. `search_tourism_by_area`
2. `search_tourism_by_location`
3. `search_tourism_by_keyword`
4. `search_festivals_and_events`
5. `search_accommodations`
6. `get_tourism_common_info`
7. `get_tourism_intro_info`
8. `get_tourism_detail_info`
9. `get_tourism_images`
10. `get_sync_list`
11. `get_legal_district_codes`
12. `get_classification_codes`
13. `get_area_codes`
14. `get_category_codes`

Tool schemas and endpoint parameter mappings are maintained under
`src/mcp_server/tools/` and `src/mcp_server/services/tourism.py`.
